# Railway template assets

Public images for AvgSoft's Railway template listings: icons, architecture diagrams and banners. One folder per template.

| Template | Files |
| --- | --- |
| [n8n (workers + internal Redis + webhook processor)](https://railway.com/deploy/fes8j0) | [n8n-queue-mode/](n8n-queue-mode/) |

Link files through jsDelivr, for example:
`https://cdn.jsdelivr.net/gh/mikedepo/railway-template-assets@main/n8n-queue-mode/icon.svg`

`n8n-queue-mode.svg` at the root is the old icon path, kept until the live listing points at the new one.
