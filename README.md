# Railway template assets

Public images for AvgSoft's Railway template listings: architecture diagrams, banners, and icons when a product has no logo on Railway's devicons. One folder per template.

| Template | Files |
| --- | --- |
| [n8n (workers + internal Redis + webhook processor)](https://railway.com/deploy/fes8j0) | [n8n-queue-mode/](n8n-queue-mode/) |

Link files through jsDelivr, for example:
`https://cdn.jsdelivr.net/gh/mikedepo/railway-template-assets@main/n8n-queue-mode/architecture.png`
