# Railway template assets

Public images for AvgSoft's Railway template listings: icons, banners and architecture diagrams. One folder per template.

| Template | Files |
| --- | --- |
| [n8n (workers + internal Redis + webhook processor)](https://railway.com/deploy/fes8j0) | [n8n-queue-mode/](n8n-queue-mode/) |

Link files through jsDelivr, pinned to the commit that added them so a change shows at once:
`https://cdn.jsdelivr.net/gh/mikedepo/railway-template-assets@<commit>/<slug>/<file>`
